# QuizEz_Project
Project made as an assignment (Technical Training 1)

Opis projektu na zaliczenie z przedmiotu „Szkolenie Techniczne 1”.


Temat projektu: Aplikacja desktopowa przeznaczona do quizów „QuizEZ”.

Projekt wykonywany w zespole dwuosobowym

Opis aplikacji:

Aplikacja desktopowa QuizEZ będzie umożliwiać tworzenie, zarządzanie i rozwiązywanie quizów z różnych dziedzin nauki. Program będzie przeznaczony dla osób chcących przetestować swoją wiedzę, a także dla uczniów i nauczycieli do wykorzystania w szkole.

Wymagania nietechniczne:

Aplikacja powinna zapewniać intuicyjny interfejs użytkownika, zrozumiały dla wielu grup wiekowych, możliwość pracy lokalnej (offline) oraz być skalowalna.

Wymagania techniczne:

Obsługa wyjątków:

•	Brak połączenia z bazą danych

•	Nieprawidłowe dane wejściowe lub wyjściowe

•	Próba wykonania operacji na nieistniejących zasobach (np. quiz, użytkownik)

Walidacja danych:

•	Walidacja danych przy rejestracji użytkownika (np. unikalność nazwy użytkownika, minimalna długość hasła)

•	Sprawdzenie poprawności danych przy logowaniu

•	Walidacja danych wejściowych podczas tworzenia i edytowania quizów (np. pytanie nie może być puste)

Poprawny zapis i odczyt:

•	Użytkownicy (konto, hasło, historia wyników)

•	Quizy (pytania, odpowiedzi, kategorie, poziomy trudności, czas)

•	Wyniki quizów (data rozwiązania, liczba punktów, procent poprawnych odpowiedzi)
 
Podstawowe funkcje aplikacji:

•	Zakładanie konta użytkownika, logowanie się lub korzystanie jako gość oraz customizacja profilu użytkownika.

•	Wybór quizu z listy dostępnych lub utworzenie nowego.

•	Rozwiązywanie quizu (również z opcją czasową).

•	Podsumowanie, punktacja na końcu quizu i porównanie z poprzednimi wynikami.

•	Możliwość usuwania i edycji quizów.

•	Ustawianie poziomu trudności quizu oraz limitu czasowego na jego rozwiązanie.

•	Możliwość przeglądania wyników dla konkretnych, wcześniej rozwiązanych quizów.

Wykorzystane technologie:

•	Java – główny język programowania

•	JavaFX – do tworzenia interfejsu użytkownika

•	SQLite – baza danych dla aplikacji

•	Doxygen – generowanie dokumentacji

•	Maven – budowanie projektu

•	GitHub (Git) – kontrola wersji
